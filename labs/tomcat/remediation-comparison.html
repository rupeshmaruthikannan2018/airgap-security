Conclusion

The DefaultServlet configuration mitigation was successfully applied. Before remediation, the server accepted the controlled PUT request. After remediation, the same type of controlled write operation was blocked with HTTP 405, while the Tomcat service remained reachable.

The underlying Tomcat software was not upgraded during this remediation. The server remains on version 9.0.98, while the fixed Tomcat 9.x version is 9.0.99. Therefore the result is MITIGATED_BUT_VERSION_STILL_AFFECTED, rather than a claim that the software itself has been fully patched.
